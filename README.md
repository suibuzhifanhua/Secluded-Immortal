## 1. 这是什么

单文件、零依赖的中文修仙**文字放置**游戏：整个游戏就是 [`仙界闭关小能手.html`](仙界闭关小能手.html)（约 420 KB，一段样式 + 一段游戏逻辑 IIFE + 一段本地助手 IIFE），双击即在浏览器运行，无需构建、无需服务器、断网不影响任何核心功能（只有"大模型助手"需要本机模型服务）。

- **主题**：你是太虚门一个最下等的杂役，偶然拾得一只**只藏不显**的聚宝盆，从此走凡人流苦修路线——攒灵石、修功法、渡劫、飞升，直到入神界封号。
- **玩法骨架**：点击修行/探索 → 突破（17 境 × 9 层）→ 解锁 50 个子系统 → 卡层时转世重开此生（带跨世资产）→ 混元九层后飞升进入神界终局阶梯。
- **一句话定位**：一个"数值与反馈都很透明"的挂机游戏——所有产出的总开关（全局倍率 = 24 项乘数连乘）在界面上实时可读。

## 3. 核心循环

```
修行/探索 → 灵石 + 修为 → 建建筑 · 淬属性 · 炼丹 · 法宝 · 道场 → 突破（层满跨境）
     ↓                                                    ↓
 卡层（缺灵石/缺修为）                       化神起可【转世】 · 混元九层可【飞升】
     ↓                                                    ↓
 攒资源、换路线（道统/姿势）        转世：带气运/祝福/天命重开此生，起点更高
                                                     飞升：凝秩序 → 晋位阶 → 神域道场
                                                              ↓
                                                    【封号神帝 · 通关此界】→ 继续转世刷长线
```

**寿元**是这条循环的隐性计时器（内部"1 秒 = 1 日"，界面上"寿元告急"有两次警告：耗尽八成、只剩 5%）。**寿元耗尽不是游戏结束**——会自动碎丹转世并随机带走一条轮回祝福；延寿丹每瓶再加 100 年缓冲。

## 4. 数值骨架（真实公式）

### 4.1 成长门槛

| 项 | 公式 |
|---|---|
| 突破所需修为 | `floor(80 × 3^境界 × 1.7^(层-1))` |
| 突破所需灵石 | `floor(10 × 3.2^境界 × 1.8^(层-1))` |
| 建筑成本 | `floor(基础价 × 逐级倍率^已建级)`（基础价见 §5.2） |
| 功法淬炼 | `floor(800 × 4^已淬阶)`，12 阶 |
| 聚宝盆温养 | `floor(10000 × 1.85^级)`，30 级（每级全局 +3%，跨世保留） |
| 丹药价格 | `floor(基础价 × 2.4^境界 × (1 − 10%×毒之大道) × 道统修正)` |
| 秘境花费 | `档位价 × 2^境界`（翠屏山 0 / 凤鸟血潭 200 / 天棺神墓 1000） |
| 天劫供奉 | `floor(5000 × 2^境界)`，冷却 3600s，上限 10 枚劫印，每枚全局 +2% |
| 神格晋阶香火 | `floor(400 × 3.2^当前阶)` → 400 / 1280 / 4096 / 1.31万 / 4.19万 / 13.4万 / 42.9万 / 137万 / 439万 |
| 喂灵兽 | 狐 `100 × 2^等级`（25 级封顶）；白虎 `300 × 2^等级`（20 级封顶） |

### 4.2 战力（斗法与石台都拼它）

```
power = 1.6^境界 × 100
      × (1 + 2%·肉身 + 2%·神识 + 1%·魂魄 + 2%·道心)
      × (1 + 5%·功法阶)
      × (1 + 4%·狐等级 ×进化?1.5 + 3%·白虎等级 ×进化?1.5)
      × (1 + 1%·大道总层)
      × (1 + 法宝战力占比)
      × (1 + 2%·结缘数 + 1.5%·劫印) …
```

### 4.3 突破成功率

- 1~8 层：**必定成功**。
- 第 9 层（巅峰）跨境：`clamp(1 − 4%×境界 + 2%×min(道心,20) + 2%×min(护名,5) + (梁画秋?+3%) + (静纹?+1%) + 天命加成 + 四纹共鸣加成, 50%, 100%)`；已是最后一境时恒为 0（无路可走）。
- 失败惩罚：扣修为（按境界计）。

### 4.4 离线

- 上限 **8 小时**（28800 秒），超出部分不结算。
- 效率 `0.5 + (苏真真结缘 ? 0.10 : 0) + 道统修正`。
- tick 100ms、自动存档 15s、关页面前存档；后台标签页被浏览器节流时，日课 / 周愿 / 支线的过期判定与前台走同一条分支。

## 5. 系统详解

> 按界面分组（7 组模块）说明。

### 5.1 修行（cult 组，开局可做）

| 系统 | 机制 | 关键数值 |
|---|---|---|
| **修行（修炼）** | 点击 / 自动积累修为，是"卡层"时的兜底动作 | 每次点击收益 `(基础 + 属性/功法加成) × 全局倍率`，12 阶功法每阶 +50% |
| **探索（巡游）** | 有冷却，产出灵石 + 修为，**并驱动事件 / 异兽遭遇 / 遗宝残片 / 洞窟门** | 基础 `(10 + 3×肉身) × 全局倍率`，藏经阁每级 +10% 探索收益、+1% 事件率 |
| **突破** | 修为 + 灵石双门槛，推进层 / 境 | 见 §4.1 / §4.3 |
| **属性淬炼** | 属性点四项：神识（修为收益）、肉身（灵石收益与战力）、魂魄（异兽与机缘概率）、道心（巅峰突破率与魔劫抗性，上限 20 点计分） | 属性点来自境界与转世 |
| **闭关洞府 / 灵田 / 药圃** | 三类稳定产出的建筑 | 起价：灵田 15 / 药圃 120（筑基起）/ 闭关洞府 400（金丹起），逐级涨价 |
| **无尽石台** | 逐层攀登的战力检验器，每层拼 `power`；峰值与当前层分别记录 | 成就以 36 / 38 层为天花板；每层给石台令与修为 |
| **石台宝库**（6 合体解锁） | 用石台令买五料，全部是**永久**加成 | 道韵 10 令/阶（封顶 50，全局 +1%/阶）、气运结晶 25（20）、不动道心 40（10）、缩地法则 60（10）、秩序残片 150（36） |

## 6. 日常 · 周常 · 留存线

### 6.1 今日道课（8 类课目，每天按日期定出 3 桩）

| 课目 | 目标 | 香火 | 石台令 |
|---|---|---|---|
| 巡游 N 次 | `20 + 5×神格阶` | 8 | 3 |
| 修炼 N 次 | 80 | 5 | 1 |
| 炼丹 N 次 | 3 | 10 | 2 |
| 登台 N 次 | 2 | 8 | 5 |
| 斗法 N 胜 | 1 | 12 | 0 |
| 炼制 N 次 | 2 | 6 | 2 |
| 施展神通 N 次 | 3 | 8 | 2 |
| 突破 N 次 | 2 | 10 | 0 |

了结每门另得 `(500 + 2000×境界) × 全局倍率` 灵石。

### 6.2 本周三愿（8 类里抽 3 条，每条都含 1 枚混沌秩序）

| 愿 | 目标 | 香火 | 石台令 |
|---|---|---|---|
| 巡游 | 250 | 60 | 60 |
| 登台 | 25 | 40 | 120 |
| 斗法胜 | 8 | 80 | 40 |
| 炼丹 | 40 | 50 | 50 |
| 门人复命 | 15 | 60 | 40 |
| 突破 | 12 | 70 | 30 |
| 炼制法宝 | 10 | 60 | 60 |
| 施展神通 | 20 | 45 | 45 |

**进度是差分值**：`当前计数 − 周初快照`，所以本周开头已经做过的事不会白送。三愿皆偿另给 **+150 香火 / +150 令 / +1 秩序**，并累计"周愿圆满"。

### 6.3 全勤与连续

- 三课全清当天：**+20 香火、+10 石台令**，且**每个自然日只发一次**（同日因转世重做日课，只照发课业本份，不再发全勤、也不加累计天数）。
- 连续全勤按本地日相接：昨天全勤过才 +1，断一天归 1；**同一自然日内重做不算断也不算两天**；把系统时钟往前拨刷不出纪录。

### 6.4 明日课表（推算型 UI）

日课与周愿都由日期哈希决定，所以"明天哪三桩课、下周哪三条愿"**今天就能算出来**。界面写的是**推算**，并明说"今天做的数不带进明天"。

### 6.5 前程 · 还差多少（只读表）

- **临门一脚**分两层：**就近**（未点亮且算得出进度的成就里差得最近的三条）与**远方 · 此世之志**（终局与圆满类成就里最近的那一座，只作牵引，不发任何额外奖赏）。
- **接下来**：洞窟封印 / 石台 / 宝楼卸货 / 调息 / 改换门庭 / 弟子复命里最短的冷却预告。
- **挂着没收**（回访第一眼）：窟中带货未落袋、门人待召回、可破境、课愿可偿、签到 / 采集 / 秘境未做、天象丹力未散。
- **每一行都能点**：成就行跳去成就簿那条并闪两下，在途行跳到对应模块（窄屏先展开那一组再滚）。
- 部分成就可算出完成百分比；条件不是单一数字的算不出进度，界面不硬凑，只写「可追 N 项」。
- 这张表**只读**：不发奖励、不改数字、不占助手决策位。

## 7. 倍率构成与上限

所有产出的总开关 = **24 项乘数连乘**（`GM_PARTS`，「修炼产出」面板有一行实时读数）。主梯不设额外的顶：境界 `×1.8/境`（第 16 境 ≈ ×12144）、神格 `×1.25/阶`、道场（×1 → ×110）——它们的顶由表长本身给。

跨世累积的五条长线项带膝点与封顶，前期（头几个时辰 / 头几世能拿到的量）手感与线性成长一致，后期增速逐级放缓：

| 项 | 规则 | 封顶 |
|---|---|---|
| 气运 | 前 15 点每点 +10%，之后每点 +2% | ×3 |
| 转世 | 前 6 世每世 +50%，之后每世 +15% | ×8 |
| 轮回祝福 | 10 层内每层 +5% | ×1.5 |
| 天命印记 | 前 25 条每条 +2%，之后每条 +0.05% | ×2 |
| 主线抉择 | 前 15 次每次 +3%，之后不再叠加全局 | ×1.45 |

## 8. 助手代打与本地大模型

顶部页签 **「大模型助手」**（面板标题「大模型助手 · 闭关顾问」），分四卡：模型接入 / 参数 / 自动闭关 / 剧情生成。

- **接入**：支持本机 Ollama `/api/chat` 与任意 OpenAI 兼容端点（地址与模型在面板自填），连接检测 + 超时 + 退避重试。
- **决策**：模型输出严格 JSON，动作过白名单 + 可执行集合校验；解析会剥掉代码围栏与夹带文本。
- **兜底**：模型不可用 30s 内自动走 `ruleAction` 贪心（日常 > 突破 > 建造 > 属性 > 探索 > 修炼），**游戏照常推进，不需要模型也能玩**。
- **剧情**：event / npc / quest 三类，模型只决定"发不发奖励"，**数额一律由游戏按境界与全局倍率定标**；支线时限钳在 5~60min；模型不可用时降级为内置佚文。
- **性格三档**：苟道 / 中道 / 搏命——只是"胆量旋钮"（敢不敢渡劫、敢不敢深入），不改任何数值规则。
- **姿势预设**：三套内置（苟道 / 中道 / 搏命）+ 「存我这套」（把你当前的开关组合存成第四套）。
- 配置独立存 `jxp_assist_cfg`，"重置游戏"不清空它。

## 9. 新手路线建议

1. **第一天**：点修行 + 探索，攒够就突破；灵石优先灵田 → 药圃（筑基）→ 闭关洞府（金丹）；每天把三桩日课偿掉拿全勤（+20 香火 / +10 令）。
2. **第一周**：周愿的进度是**差分值**——本周从周初快照之后做的事才算数。把贡献喂宗门，职位每阶全局 +2%。
3. **筑基**：选**道统**（这是本作唯一真正的"取舍"），换派有冷却与因果代价；打天骄拿首胜 → 大还丹丹方。
4. **化神**：营建炼丹房；从这里开始可以**转世**——第一次转世是长线真正的起点（气运与祝福从此滚起来）。
5. **元婴 ~ 大乘**：道场一路开辟（×1.6 → ×5），万宝楼学会"买信息"（盲买是零期望），洞窟深入按"层数递增 / 风险步进 0.04"自己算该在哪层收手。
6. **仙界**：石台宝库五料优先**道韵**（全局 +1%/阶，封顶 50）与**气运结晶**；攒 36 枚秩序准备飞升。
7. **神界**：位阶香火 `400×3.2^n` 涨得极快，先把器灵里 **聚宝财灵（+12% 全局）** 当成长期目标；神域三处道场是终局倍率的大头。

## 10. 界面与操作

- **模块胶囊**：顶部 7 组入口（修行 / 终局 / 日常 / 资源 / 伙伴 / 挑战 / 远方），窄屏（≤1023px）下一次只看一个模块，末尾「全 展 开」一键回到全展开；偏好存 `jxp_grp`（不进存档）。**宽屏一律全部展开，只是滚动定位。**
- **页签**：底部页签包含成就簿、典籍（48 条，分 7 组 + 顶部跳转）、大模型助手等。

- **布局**：280 ~ 1920px 多档宽度下均无横向溢出，间距随屏宽单调递增。
